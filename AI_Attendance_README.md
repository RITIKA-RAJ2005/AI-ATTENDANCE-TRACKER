# AI-Based Smart Attendance Monitoring System

A face-recognition attendance system built with OpenCV. It detects and
recognizes faces from a webcam feed and automatically logs attendance
(name, status, check-in, check-out) — no manual roll call needed.

## How it works

1. **Register** — capture ~60 face images per person via webcam.
2. **Train** — an LBPH (Local Binary Patterns Histograms) face recognizer
   learns to distinguish each registered person.
3. **Monitor (GUI)** — a desktop app shows the live camera feed and a
   status table. Everyone starts the day "Absent"; when the camera sees
   them, they flip to "Present" (or "Late" if after the cutoff time),
   with check-in and check-out times tracked automatically.
4. **Report** — generate a polished Excel dashboard summarizing
   attendance % per person across all days, with a chart.

## Requirements

```bash
pip install opencv-contrib-python numpy pillow openpyxl
```

> Note: `opencv-contrib-python` is required (not just `opencv-python`)
> because it includes the `cv2.face` module used for LBPH recognition.
> `pillow` is needed for the GUI's live video display.
> `openpyxl` is needed for the Excel report.

A webcam is required to run this locally.

## Usage

Run the scripts in order, from the project folder:

```bash
# 1. Register each person (run once per person)
python AI_Attendance_1_Register_Faces.py

# 2. Train the model on everyone registered so far
python AI_Attendance_2_Train_Model.py

# 3. Start the attendance GUI (Start/Stop buttons, live table)
python AI_Attendance_3_Mark_Attendance.py

# 4. Generate an Excel attendance report/dashboard
python AI_Attendance_4_Generate_Report.py
```

In the GUI window: click **Start Camera** to begin monitoring, **Stop
Camera** to end the session (attendance is saved automatically either
way, including if you close the window directly).

## Customization tips

- **Accuracy**: increase `SAMPLES_TO_CAPTURE` in
  `AI_Attendance_1_Register_Faces.py` for more training images per
  person, and register with slightly varied angles/expressions and
  good, even lighting for best results.
- **Sensitivity**: adjust `CONFIDENCE_THRESHOLD` in
  `AI_Attendance_3_Mark_Attendance.py`. LBPH confidence is a *distance*
  score — lower means a better match. Lower the threshold to reduce
  false positives, raise it if real people aren't being recognized.
- **Late cutoff**: change `LATE_AFTER_TIME` in
  `AI_Attendance_3_Mark_Attendance.py` (24-hour `HH:MM:SS` format) to
  set when a check-in counts as "Late" instead of "Present".
- **Re-registering someone**: just run
  `AI_Attendance_1_Register_Faces.py` again with a new name, then
  retrain with `AI_Attendance_2_Train_Model.py`.
- **Adding more people later**: register the new person, then simply
  rerun `AI_Attendance_2_Train_Model.py` — it retrains on the full
  dataset each time.
- **Deep-learning upgrade**: for higher accuracy (especially with
  masks, angles, or larger crowds), swap LBPH for an embedding-based
  approach using the `face_recognition` library (built on dlib) or a
  pretrained model like FaceNet/ArcFace — the registration/logging
  structure here stays the same, only the recognizer changes.

## Notes

- Attendance is stored as plain CSV, one file per day, so it's easy to
  import into Excel, Google Sheets, or a database — and `AI_Attendance_
  4_Generate_Report.py` will automatically combine all of them.
- "Absent" only means "not seen by the camera during that day's
  session" — the system doesn't know about days it wasn't run at all.
- This is a local/offline system — no data leaves your machine.
